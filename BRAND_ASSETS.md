## Using Orkaid branding

Third parties must not use Orkaid branding — the name, logo, wordmark, or visual identity — in a way that suggests:

- affiliation with Orkaid,
- endorsement by Orkaid,
- certification by Orkaid, or
- official Orkaid status,

unless explicitly and separately authorized.

## Optional attribution

If Orkaid code materially contributes to a third-party public implementation, visible attribution to Orkaid is welcome, but it is entirely **optional** — it is not an additional condition of the MIT License.

Suggested optional textual credit:

```
Based on Orkaid — https://orkaid.de
```

or:

```
Built with Orkaid — https://orkaid.de
```

Text-only attribution like the above does not require use of the Orkaid logo, and does not by itself grant any additional branding rights beyond that plain text credit.
